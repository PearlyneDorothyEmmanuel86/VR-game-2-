Description of game: There is a righthand controller with a green sphere attached acting as a hand and the left hand controller has a pink sphere attached. When the righthand controller's green ball hits the blue quad, the blue quad turns orange. When the left hand controller's pink ball hits the grey cube, the grey cube becomes a grey cylinder.
